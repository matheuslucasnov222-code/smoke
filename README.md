# 👻 SMOKE BLACK - Estilo, Cachos e Atitude

Bem-vindo ao repositório oficial da **Smoke Black**, uma aplicação web interativa focada em produtos de cuidados capilares, acessórios e estilo para cabelos cacheados e crespos.

---

## 🚀 Sobre o Projeto

O projeto foi desenvolvido em **HTML5, CSS3 e JavaScript puro**, trazendo uma interface moderna com temática sombria/fantasmagórica (`#08060e`), listagem completa de produtos separados por categorias, sistema de busca em tempo real, gerenciamento de favoritos, carrinho de compras interativo e fluxo completo de finalização de pedidos.

---

## 🛠️ Estrutura do Repositório

O projeto é composto pelos seguintes arquivos principais:

*   **`index.html`** - Estrutura HTML principal contendo todas as telas da aplicação (login, loja, favoritos, carrinho, checkout, confirmação e perfil).
*   **`style.css`** - Folha de estilos customizada com design responsivo, animações e layout otimizado.
*   **`script.js`** - Lógica interativa de navegação entre telas, gerenciamento do estado da aplicação, manipulação do carrinho e filtros de produtos.
*   **`README.md`** - Documentação do projeto.

---

## 📦 Funcionalidades

* **Coleção de Produtos:** Pentes garfo, durags, toucas de cetim, cremes de hidratação, finalizadores e óleos.
* **Sistema de Busca e Filtros:** Encontre rapidamente o produto desejado por nome ou categoria.
* **Favoritos e Carrinho:** Salve seus itens preferidos e calcule o valor total dos pedidos instantaneamente.
* **Design Responsivo:** Adaptado para telas de celulares e computadores com navegação fluida por menu inferior.

---

## 💻 Como Executar

1. Clone o repositório para o seu ambiente local ou abra diretamente no **GitHub Codespaces**.
2. Abra o arquivo `index.html` em qualquer navegador web moderno para visualizar a aplicação em funcionamento.
